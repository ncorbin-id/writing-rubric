# Writing self-assessment with rubric

A writing activity where learners respond to a prompt in a rich-text editor, then self-assess against a rubric you define. Learners review their own writing one criterion at a time by highlighting the evidence that supports each one, then selecting their score before seeing a final total and your closing message. The prompt, rubric criteria and levels, colors, and conclusion are all editable from the authoring form.

Developed for use in (https://designwithmighty.com/studio/templates/writing-self-assessment-with-rubric-ad6bcfdc-cae4-4a47-8082-8a269144c951)[Mighty Studio].
